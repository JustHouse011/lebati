# Lebati

A public landing page for a South African responsible gambling access and compliance technology platform.

## Local development

Use Node.js 24.

```sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm run build
```

The enquiry form validates input in the browser. Delivery requires an integration. The operator workflow illustrates proposed capabilities.

## Scene navigation

The scroll controller measures chapter and verification stops from the page layout. Scroll position drives one reversible camera path through the WebGL world. The chapter rail and arrow keys jump between stops. In the verification chapter, each step button targets its corresponding camera position. The reduced-motion and WebGL fallback views expose all four steps as ordinary HTML.

## Visual assets

The projected South Africa outline and static map fallback derive from Natural Earth's 1:50m Admin 0 Countries dataset, version 5.1.2, released into the public domain. The landing page uses a temporary typographic wordmark. The illustrated network nodes are decorative.

[Natural Earth downloads](https://www.naturalearthdata.com/downloads/) · [Terms of use](https://www.naturalearthdata.com/about/terms-of-use/)

The extruded chapter lettering uses Inter 4.1 outlines under the SIL Open Font License. See the [Inter project](https://github.com/rsms/inter) and the included `src/assets/inter-OFL.txt`.
